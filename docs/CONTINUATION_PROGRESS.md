## Việc tiếp theo cần môi trường thật

1. Cấp môi trường Supabase staging riêng; sao lưu và chạy bốn SQL theo thứ tự README trước khi đưa code mới lên. Code mới cần RPC và bảng CRM, sẽ báo lỗi nếu migration chưa có.
2. Lặp lại A/B, clone/editor/publish, CRM nhiều thiết bị, token hết hạn/refresh và webhook sandbox trên Auth/PostgREST thực. Xác nhận OAuth redirect, upload/storage, chính sách camera/QR và hiệu năng CDN trên desktop/mobile thực.
3. Xem kết quả CI trên GitHub, build/run Docker và đo độ trễ Supabase thật. Chỉ triển khai production khi có chỉ thị riêng; không dùng giao dịch ngân hàng hoặc thiệp khách để thử.
